# 🍽️ Restaurant Bill Generator

A simple Restaurant Bill Generator built using **HTML, CSS, and JavaScript**. It allows users to select food items, enter quantities, and automatically generates the bill with **5% GST**.

## Features

* Add food items to the bill
* Calculate subtotal
* Calculate 5% GST
* Display grand total
* Remove individual items
* Clear the bill

## Technologies Used

* HTML5
* CSS3
* JavaScript (Arrays & Objects)
